What this mockup is showing

  • .hero-shader and .hero-text both use pointer-events: none — nothing in the hero layer can block clicks on the nav/toolbar/grid.
  • Default blend is mix-blend-mode: overlay; use the switcher (bottom-right) to compare screen and multiply.
  • The hero is its own stacking context (isolation: isolate) so the blend mode only composites against the shader layer, not the whole page.
  • Not shown here (behavioral, not visual): the real hero pauses rendering on visibilitychange and stays within the existing 3-megapixel canvas budget.
