Cellular Automata

A state-machine on a grid. Every cell looks at its neighbours, follows a rule, and steps forward. Complex behaviour from simple, local decisions.

The receiver's perspective

Instead of asking "where does this cell send its state?", flip it: each cell asks "what am I receiving from my neighbours this step?" Movement becomes a pull, not a push — easier to reason about and easier to make deterministic.

Birth & survival rules

A cell's next state is decided by counting live neighbours and comparing against a rule set — which counts cause a cell to be born, and which let it survive. Change the rule set and the whole character of the system changes.

Reading and writing without collisions

Each step reads the previous frame and writes a fresh one, so a cell never reads a value that has already been updated this tick. Keeping the two frames separate is what makes the simulation stable.
