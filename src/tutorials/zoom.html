Faking 3D with four zooming layers

One flat, tiling image. Four copies of it, each parked at a different point in the same slow zoom and crossfaded so the motion never stops and never pops. Your eye reads continuous depth — no perspective, no parallax, just looming and handoff.

The idea — depth from a single flat image

There's no 3D scene here and no camera. The trick leans on two of the oldest monocular depth cues your visual system has: looming (something that steadily grows is coming toward you) and relative size (of two identical things, the smaller one is farther away). If you take one flat image and continuously magnify it, that reads as flying into it. If you show several magnifications at once, the small ones sit "back" and the large ones sit "up front", and suddenly a single texture has a front-to-back stack.

A single zooming layer has one problem: it can't zoom forever. Sooner or later it's magnified so hard it's a blurry smear, and you have to snap it back to the start — a visible pop. The fix is the entire technique: run several layers through the same zoom, staggered in time, and crossfade between them so that whenever one layer reaches its ugly end, another has already faded in at the start to carry the picture. The reset always happens while a layer is invisible.

The buffer setup that makes it work

This lives in a three-pass Shadertoy graph. Only the middle pass is the effect; the setup around it is what lets the zoom exist at all.

Buffer A is the flat source (in the original piece, a circuit automaton). For this effect its only job is to be sample-able anywhere, at any scale. That's why its texture is set to wrap: repeat: sampling far outside the normal 0–1 range just tiles the image, so a zoomed-out layer never runs into an edge or a seam. The source packs its brightness into one channel, .y, which is all we read.

Buffer B is this pass. It samples Buffer A on iChannel0 and composites the layers. Two sampler settings on that input are load-bearing:

The two settings that matter: wrap: repeat means no seams at any zoom level — every layer, however far out, lands on valid tiled texture. filter: linear means the near, heavily-magnified layers interpolate smoothly instead of showing giant hard pixels. Switch to nearest and the front of the tunnel goes blocky; switch to clamp and the far layers smear at the frame edges. Get these two right and the rest is arithmetic.

Image is a cosmetic radial-blur and vignette pass. It's out of scope here — the depth is already fully built by the end of Buffer B.

The zoom, as a graph

Inside Buffer B, every pixel runs the same short loop, once per layer, and sums the results. Each node below is one line of that loop paired with the exact GLSL. Read top to bottom and you have the whole compositor.

coordinates

Centre the pixel and make it aspect-safe

Shift the origin to the middle of the screen so the zoom pulls toward the centre, and divide by height (not width) so a wide window doesn't stretch the image sideways.

// U is the pixel coordinate. Recentre to [-x..x] × [-0.5..0.5] and keep
// the aspect ratio square by dividing both axes by the height.
vec2 uv = (U - 0.5*iResolution.xy) / iResolution.y;
the depth clock

One number says how deep we are

A single slowly rising value drives the whole zoom. Multiply iTime down to taste. Swap it for a scroll offset and the page scrolls the viewer through the tunnel instead of time doing it.

// The master phase. Everything below is a function of T.
float T = iTime * 0.12;   // slower constant = a gentler dive
the loop · stagger

Every layer runs the same journey, evenly offset

The loop runs once per layer (ZL of them). Each layer lives the identical birth-to-reset arc, but its phase is nudged by an even slice of the cycle, so at any instant the layers are spread out across the journey rather than bunched together. mod(…, SPAN) is what makes each layer wrap back to the start when it finishes.

for(int i = 0; i < ZL; i++){
    // Same arc for everyone, shifted by i/ZL of a full cycle.
    // With ZL = 4, the four layers sit at 0, ¼, ½, ¾ of the way through.
    float t = mod(T + float(i)*(SPAN/float(ZL)), SPAN);
    // ...
}
the loop · the zoom

Shrinking the sample scale is the zoom

This is the heart of it. We sample the source at uv * scale. A large scale spreads a lot of texture across the screen, so features look small and far. As t climbs, scale shrinks toward zero, so we magnify an ever-tinier patch — features balloon and rush right up to the glass. Each layer therefore flies continuously inward.

// t goes 0 -> SPAN, so scale goes SPAN -> 0.
// big scale = zoomed out (far);  scale near 0 = zoomed way in (near).
float scale = SPAN - t;
vec2  q     = uv * scale;   // (offset added in node 6)
the loop · crossfade

A sine window fades each layer in and out

Each layer's contribution is weighted by a half-sine over its life: zero at birth, full in the middle, zero again at the reset. That's the whole reason there's no pop. A freshly-born layer (tiny, aliased) contributes nothing; a layer about to wrap (blurry, over-magnified) contributes nothing; every layer is only "loud" during its sharp middle. Because the reset happens at zero weight, it's invisible.

// 0 at t=0, 1 at t=SPAN/2, 0 at t=SPAN. Both ugly ends hidden.
float w = sin(3.14159 * t / SPAN);
the loop · decorrelate

Offset each layer so they're different depths, not clones

Every layer reads the same image. Without a per-layer shift they'd all sample identical content and the result would just be one image pulsing — no stack, no depth. A constant offset drops each layer onto a different patch of the (tiling) source, so each reads as its own plane, and each brings fresh content when it wraps. The optional rotation by 2.399 rad — the golden angle, about 137.5° — spins each layer to a new orientation so repeats never visibly line up.

// Offset is added AFTER scaling, so each layer zooms toward its own fixed
// point in the texture — a different slice of the world per layer.
vec2 q = //rot(float(i)*2.399) *      // optional: golden-angle spin
         (uv*scale)
         + vec2(float(i)*3.31, float(i)*3.17);
accumulate & normalize

Weighted sum over layers, then divide by the total weight

Add up every layer's sample scaled by its window, keep a running total of the weights, and divide at the end. That division turns the sum into a weighted average — which is exactly what a crossfade is. The max(…, 1e-3) just guards against dividing by zero if every window happens to bottom out at once.

    g    += texture(iChannel0, q).y * w;   // .y = the source's glow channel
    wsum += w;
}
// weighted average = the crossfade between all active layers
O = vec4(vec3(g / max(wsum, 1e-3)), 1.0);  // grayscale — colour it later
the tuning knob

Why four layers?

With the sine window, a lone layer is at full brightness for only an instant and dark most of the time — on its own it would visibly throb and dim. Stagger enough layers and their humps overlap so the combined weight stays healthy the whole way through. For SPAN ≈ 0.7, four is the sweet spot: always roughly two layers carrying the image. Fewer and you see pulsing and gaps; many more just costs fill-rate and muddies the picture. Set the layer count to 1 in the demo below to watch a single plane pop.

See it move

The same compositor, live and tunable. Start by dropping layers to 1 to feel the pop the crossfade exists to hide; turn on tint layers to see the depth stack as separate coloured planes; isolate one layer to watch it zoom and reset on its own.

The whole effect in one breath: one tiling image · four copies riding the same zoom, evenly staggered · each faded in and out by a sine window so the reset never shows · a per-layer offset so they read as different depths · sum, normalize, done. No perspective math anywhere — only looming and handoff.

The complete pass

Buffer B in full, assembled from the nodes above. Feed it a tiling source on iChannel0 (wrap repeat, filter linear) and it composites the tunnel:

// ============================================================
//   Buffer B  ·  the zoom compositor
//   iChannel0 = flat source, sampler: wrap REPEAT, filter LINEAR
// ============================================================

mat2 rot(float a){ float c = cos(a), s = sin(a); return mat2(c, s, -s, c); }

#define ZL   4      // layers riding the zoom at once
#define SPAN .7     // length of one layer's journey, in clock units

void mainImage(out vec4 O, in vec2 U){
    // Centre the coords and divide by height: the zoom pulls toward the
    // middle and never stretches on a wide screen.
    vec2 uv = (U - 0.5*iResolution.xy) / iResolution.y;

    // The master depth clock. Swap iTime for a scroll offset to drive the
    // dive by scrolling instead of by time.
    float T = iTime * 0.12;

    float g = 0.0, wsum = 0.0;
    for(int i = 0; i < ZL; i++){
        // Same birth-to-reset arc for every layer, offset by an even slice
        // of the cycle so the layers stay spread across it.
        float t = mod(T + float(i)*(SPAN/float(ZL)), SPAN);

        // Shrinking scale = zooming in. Big scale spreads lots of texture
        // over the screen (far); scale -> 0 magnifies a tiny patch (near).
        float scale = SPAN - t;

        // Crossfade window: 0 at birth, 1 mid-journey, 0 at reset. Both ugly
        // ends sit at zero weight, so a layer wrapping around is invisible.
        float w = sin(3.14159 * t / SPAN);

        // Per-layer offset drops each layer onto a different patch of the
        // tiling source, so they read as separate depth planes. Uncomment the
        // rotation to spin each by the golden angle (~137.5 deg).
        vec2 q = //rot(float(i)*2.399)*
                 (uv*scale)
                 + vec2(float(i)*3.31, float(i)*3.17);

        // Accumulate the source's glow channel, weighted by the window.
        g    += texture(iChannel0, q).y * w;
        wsum += w;
    }

    // Divide by total weight -> weighted average = the crossfade.
    O = vec4(vec3(g / max(wsum, 1e-3)), 1.0);   // grayscale; colour later
}
